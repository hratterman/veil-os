Veil OS

This page is served by an operating system written from scratch: its own kernel, its own TCP/IP stack, its own HTTP server, off its own FAT16 filesystem driver.

More: how this was built

What you are touching right now

  • a virtio-net driver moving raw ethernet frames
  • ARP, IPv4 and ICMP (it answers ping)
  • a hand-written TCP state machine - the handshake that delivered this page was ours on one side
  • an HTTP/1.1 server running as a preemptively scheduled kernel task
  • the browser you may be reading this in, rendering our own HTML, CSS and PNG decoders

Apps that ship with it

  • Editor - type and save text files to the FAT16 disk
  • Clock - analog and digital faces, chronograph and stopwatch, with real local time synced over NTP (it resolves pool.ntp.org through our own DNS query)
  • Paint - palette, brushes, a canvas that survives reboot
  • Browser - this site, over our own loopback TCP
  • Chat - every running Veil instance joins one room over real UDP
  • Image viewer and a WAV audio player driving Intel HDA

It also boots on a real Raspberry Pi 4, not just QEMU.
